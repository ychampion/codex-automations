# Runbook drift check

## When to use
Use this automation when you want Codex to compare operational docs to current repo reality and flag stale instructions.

## Before enabling
- Connect the correct repo or project in Codex.
- Review the prompt and adjust team-specific language if needed.
- Update the schedule, time, and timezone to match your workflow.
- Add branch-specific instructions if the run should stay scoped.

## Recommended execution environment
- Local

## Example output
- A concise automation update with grouped findings, prioritized next actions, and the most relevant evidence from recent repo activity.
